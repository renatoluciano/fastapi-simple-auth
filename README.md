# 🔐 FastAPI Simple Auth

Este é um projeto prático desenvolvido para aprender os conceitos fundamentais de autenticação web, criptografia de senhas e gerenciamento de sessões utilizando o ecossistema Python.

## 🚀 Funcionalidades

- **Cadastro de Usuários:** Criação de conta com senha criptografada.
- **Login Autenticado:** Validação de credenciais e geração de token de acesso.
- **Área Logada (Dashboard):** Página protegida que apenas usuários autenticados conseguem visualizar.
- **Logout:** Encerramento seguro da sessão.

## 🛠️ Tecnologias Utilizadas

- **Backend:** Python & FastAPI
- **Servidor:** Uvicorn
- **Autenticação:** JWT (JSON Web Tokens) via `python-jose`
- **Segurança:** Criptografia Bcrypt via `passlib`
- **Frontend/Interface:** HTML5 & Jinja2 Templates
- **Controle de Versão:** Git
